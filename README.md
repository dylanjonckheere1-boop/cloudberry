# Cloudberry — landingspagina

Landingspagina voor **Cloudberry**, een fictief theemerk: fruitige, cafeïnevrije thee voor het hele gezin.
Gemaakt voor de eindopdracht *Creatieve Automation* (Combo E) door **Dylan Jonckheere** (2026), vibe-coded met Claude.

## Inhoud

- **Hero** met slogan "Thee voor groot en klein" en CTA's
- **Smaken**: de vier smaken met productfoto's
- **Verhaal** over het merk (cloud + berry + theeblaadje)
- **Momenten**: AI-video (Adobe Firefly) en gezinsfoto's
- **Inschrijven**: ingesloten MailerLite-formulier dat de welkomstflow start
- Hover-effecten, lightbox in de huisstijl, scroll-animaties

## Bestanden

| Bestand | Wat |
|---|---|
| `index.html` | De pagina |
| `style.css` | Opmaak volgens de brand guidelines v1.3 (antraciet `#2E2E2E`, wit, Bebas Neue, Nunito) |
| `script.js` | Lightbox, scroll-animaties, header, reserveformulier |
| `assets/` | Foto's, video en logo's |

Hover-effect aanpassen: in `index.html` staat `<body data-hover="vergroten">`. Zet dat op `verkleinen` om de foto's uit te laten zoomen bij hover.
